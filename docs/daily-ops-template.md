## 4. 建议执行规则

1. 每日站会只讨论阻塞、风险、接口变更，不展开实现细节争论。
2. 任意 P0 风险必须在当日收工前给出兜底方案，不允许“待观察”。
3. 若出现跨模块改动，先更新文档再改代码，避免联调返工。
4. 每天至少完成一次可运行链路验证，保证项目始终可演示。
