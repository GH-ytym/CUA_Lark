# C 任务 Day 1：侧边栏信息架构与交互线框

## 验收结论

- 已完成 React 侧边栏线框评审版，可本地运行查看。
- 已覆盖“指令输入 → 任务卡片 → 状态流 → 结果详情”的核心信息架构。
- 当前版本使用静态演示数据，供 Day 2 路由、状态管理和真实接口接入。

## 页面区块

1. 顶部 Header：展示项目名、比赛阶段、当前版本标签。
2. Hero 说明区：说明单栏闭环、CLI 优先与 CUA 保底定位。
3. 指令入口：自然语言输入框、快捷指令、保存草稿、提交任务。
4. 任务卡片：展示任务标题、执行器、状态、耗时与回退提示。
5. 状态时间线：解析、路由、执行、校验四阶段。
6. 结果详情：链路 ID、当前阶段、失败回退、下一步占位。

## 组件拆分方案

- `AppShell`：全局框架、Header、页面容器。
- `SidebarPage`：侧边栏页面编排，组合所有业务区块。
- `CommandComposer`：聊天输入、快捷指令、提交入口。
- `ExecutionFeed`：任务卡片列表与执行状态摘要。
- `StatusTimeline`：任务生命周期展示。
- `ResultDetail`：执行详情与调试信息入口。
- `execution.ts`：前端共享任务与时间线类型。

## Day 2 建议

- 引入路由或页面状态容器，固化侧边栏主流程。
- 将静态任务数据迁移到 store 或 mock API。
- 接入 UI 主题变量，统一颜色、圆角、阴影、间距 token。
