# CHANGELOG

## v1.1.0 (2026-04-24)

### 🚀 新增功能
1. **触发规则扩展**
   - 新增3种CUA接管场景：RESULT_INVALID（CLI结果无效）、USER_REQUESTED（用户主动要求）、HYBRID_TASK_REQUIRED（混合任务协同）
   - 新增2种CUA放弃场景：USER_INTERRUPTED（用户主动中断）、MULTI_MONITOR_UNSUPPORTED（多显示器不支持）
   - 新增`CuaConfig`可配置模型，支持动态调整所有阈值和开关，无需修改代码
   - 新增`TriggerRuleEvaluator`规则评估器，实现分层降级策略（4个降级层级）

2. **动作原语扩展**
   - 新增`safe_scroll`：安全滚动鼠标滚轮，支持上下滚动
   - 新增`safe_hotkey`：安全按下快捷键组合
   - 新增`capture_screenshot`：屏幕截图能力，支持区域和全屏截图
   - 新增`verify_window_focus`：窗口焦点验证，确保操作作用到正确窗口
   - 新增DPI自动检测能力，无需手动配置缩放系数
   - 新增用户活动检测能力，检测到用户操作自动终止CUA执行

3. **安全体系增强**
   - 所有动作原语新增窗口焦点校验参数，避免操作到错误窗口
   - 所有动作原语新增用户活动检测，防止与用户操作冲突
   - 新增敏感操作黑名单机制，自动拦截密码、支付、删除等高风险操作
   - 新增多级安全校验，执行前、执行中、执行后三层检查

### 🔧 功能优化
1. **窗口匹配增强**
   - `focus_and_maximize`方法支持3种匹配方式：窗口标题、进程名、窗口类名，解决窗口标题变化导致匹配失败问题
   - 方法返回值优化为(成功标志, 窗口句柄)，便于后续操作验证
   - 新增窗口焦点二次验证，确保窗口确实前置成功

2. **原语鲁棒性提升**
   - 所有原语操作前自动校验前置条件，失败立即抛出明确错误
   - DPI缩放逻辑优化，支持自动检测和手动设置两种模式
   - 剪贴板操作优化，异常情况下也会尽量恢复用户原始剪贴板内容

3. **接口标准化**
   - 完善`__init__.py`导出所有对外接口，统一模块访问入口
   - 所有方法参数和返回值标准化，便于后端服务对接
   - 版本号升级到v1.1.0，明确模块版本标识
